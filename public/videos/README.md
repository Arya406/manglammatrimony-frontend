# Manglam Matrimony — Production Hero Video Assets

Place the production background video files in this directory:

1. `manglam-hero-desktop.mp4`
   - Resolution: 1080p or 1440p (16:9 widescreen or 21:9 cinematic ratio)
   - Codec: H.264 / AAC (web-optimized, fast-start / moov atom at beginning)
   - Audio: None or muted
   - Target bitrate: ~2.5 - 4.5 Mbps for smooth streaming

2. `manglam-hero-mobile.mp4` (Optional, mobile-optimized portrait/vertical ratio)
   - Resolution: 1080x1920 or 720x1280 (9:16 portrait)
   - Target bitrate: ~1.5 - 2.5 Mbps

*If these video files are not present, the hero seamlessly displays `/images/hero-couple.jpg` as the graceful poster fallback.*
